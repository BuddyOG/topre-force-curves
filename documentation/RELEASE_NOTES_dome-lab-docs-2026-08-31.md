## Scientific continuity

This release does not change raw acquisitions, retained-run membership,
canonical evidence, metrics, index formulas, the 68-dome reference fleet,
viewer bytes, or EC Parts Builder behavior. The frozen identifiers remain
`metrics-v4.2`, `intake-qc-v1.4`, and `perception-rank-v1`.

The prospective protocol does not itself create participant evidence. It must
be frozen before enrollment, and its results must not be backfilled into an
existing released index without a new model version and provenance record.
