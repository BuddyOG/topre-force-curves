Force Curve Bench documentation

Method, interpretation, provenance, limitations, release notes, and reproducibility material for Force Curve Bench fc-3.4.

Release identity: The canonical viewer is buddyog.github.io/topre-force-curves and the frozen Git tag is fc-3.4. Package hashes are recorded in FORCE_CURVE_BENCH_RELEASE_MANIFEST.json and SHA256SUMS.
Repository continuity: fc-3.4 preserves all 184 existing raw CSV paths and the legacy dome-lab.html, dome-lab-parts.html, and ec-switch-explorer.html endpoints byte for byte. The root index.html and README.md are intentionally replaced. A root .gitattributes containing * -text prevents Git line-ending normalization, and an empty .nojekyll prevents GitHub Pages from filtering underscore-prefixed paths. Both are release infrastructure, not source evidence. The legacy pages are retained for URL continuity and were not revalidated as part of fc-3.4.
